# Data and input requirements

This repository contains analysis code, not research data. It does not include patent records, citation panels, paper or financial-report text, cluster keyword tables, embeddings, feature arrays, fitted models, predictions or SHAP arrays.

The scripts require project input files and selected-configuration JSON files that must be obtained from their providers or the research team under the relevant access terms. Their exact filenames and expected schemas are referenced in the scripts. Before running a script, inspect its input checks and confirm that the files are the corrected, filtered/merged versions for the same cluster scheme.

For the dissertation, cite the primary source of the patent citation counts and describe the derivation of the annual panel. Do not treat financial-report reporting-period year as proof that report text was publicly available in that year; report-level release dates were not available for the reported analysis. The keyword clusters and embedding files are withheld for separate publication, as requested by the project team.
