# Data directory

Input files are not included in this repository. Obtain them through the original data providers or the project team, and place local working copies here only if your access terms allow it. Do not commit data files: `.gitignore` excludes common tabular and array formats.

The keyword-cluster tables and embedding arrays are intentionally not redistributed; they are intended for separate publication. Patent citation counts should be cited to their original data source rather than hosted here. See `../docs/DATA_AND_INPUTS.md`.
